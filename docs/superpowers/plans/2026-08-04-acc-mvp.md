# Agent Capability Compiler MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify a complete read-only REST-to-MCP ACC MVP with deterministic packs, a generic runtime, an engineer skill, and a FastAPI CRM acceptance fixture.

**Architecture:** Strict YAML contracts compile to normalized JSON IR and a deterministic ZIP pack. A fixed runtime validates and executes bounded workflows against one configured HTTP origin and exposes capabilities over MCP stdio.

**Tech Stack:** Python 3.12, uv workspace, Pydantic v2, PyYAML, JSON Schema Draft 2020-12, httpx, FastAPI, pytest, Ruff, mypy.
